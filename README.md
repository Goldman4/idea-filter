# Idea Filter

Idea Filter is a small tool for evaluating digital product ideas.

## Problem

I want to create useful digital products, but I need a simple way to evaluate ideas before spending time on them.

Many ideas can sound interesting, but not every idea has a real user need, clear value, or realistic first version.

## User

The first user is me: a beginner digital product creator who wants to choose better ideas and learn product thinking through practice.

## Main Goal

The tool should help evaluate a product idea and decide what to do with it:

- do it
- improve it
- postpone it

## Input

The user enters:

- idea name
- idea description
- target audience
- user problem or pain
- possible monetization
- personal interest

## Output

The tool gives:

- score from 0 to 100
- strengths of the idea
- weak points
- recommendation
- next steps

## Evaluation Criteria

The first version should evaluate ideas by:

- real user pain
- clear target audience
- simplicity of first version
- monetization potential
- personal interest
- confidence in the information

## First Example

Idea: English speaking practice bot

Description: A bot that helps users practice English through text or voice conversations. It can continue the conversation, find mistakes, and suggest better phrases.

Possible value: users can practice English without needing a human tutor every time.
